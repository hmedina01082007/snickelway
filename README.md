# Snickelway

App web para preparar el C1 de inglés antes de un año en York: vocabulario con repaso espaciado, lecturas, readings generados automáticamente y minijuegos.

Ábrela en: https://hmedina01082007.github.io/snickelway/

- Tus datos se guardan solo en tu navegador. Usa **Hoy → Copia de seguridad** para pasarlos a otro dispositivo.
- Opcional: conecta tu propia clave gratuita de Gemini en **Hoy** para que escriba artículos, traiga palabras y explique las que consultes. La clave se queda en tu navegador.
- Sin clave usa fuentes abiertas: Datamuse y Free Dictionary API (palabras), Wiktionary (expresiones, CC BY-SA), Wikipedia (artículos, CC BY-SA) y MyMemory (traducciones).
